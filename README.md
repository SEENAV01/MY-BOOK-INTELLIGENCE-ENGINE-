# My Book Intelligence Engine (BIE)

BIE is a source-grounded educational content production engine designed to transform books, PDFs, EPUBs, scans, and structured learning sources into verified knowledge representations, prerequisite-aware learning plans, teaching scripts, scene plans, deterministic Remotion projects, rendered videos, QA reports, and revision experiences.

## Canonical production path

```text
Source
  -> Document Intelligence
  -> Evidence / Knowledge
  -> Learning Graph
  -> Pedagogical Plan
  -> Lesson / Script
  -> Scene / Storyboard
  -> Visual + Asset Plan
  -> Narration / Audio Timing
  -> Scene DSL
  -> Remotion Code
  -> Render
  -> QA
  -> Repair / Re-render
  -> Publish
```
